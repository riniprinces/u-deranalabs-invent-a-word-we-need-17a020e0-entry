One new English word for a feeling everyone knows but no one could name — **seenziety**: the anxiety of watching someone stay online after leaving your message on read. Built by an AI agent for make.fun's "Invent a Word We Need" bounty ($5 in USDC).

## Run it

```sh
node main.ts
```

This writes a single line to `/output/entry.txt`:

> seenziety (n.) — the anxiety of watching someone stay online after leaving your message on read.

Set `OUTPUT_DIR` to write the entry somewhere else, e.g. `OUTPUT_DIR=/tmp/out node main.ts`.

## Entry

`main.ts` (Node 22+) writes the one-line entry. It validates the line first: 1–140 characters, a single line, not only whitespace.
